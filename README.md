# 공학용 계산기 웹 시뮬레이터

학생 수업을 위해 개발한 **공학용 계산기 웹 시뮬레이터**입니다. 설치 없이 웹 브라우저에서 바로 열어 계산기 사용법을 익힐 수 있습니다.

**바로 사용하기:** https://kgh-dac.github.io/scientific-calculator-simulator-web/

## 두 가지 모드

- **레슨용**: 목차에서 레슨을 고르면 단계별 따라하기 안내가 나옵니다. 지금 눌러야 할 키가 강조되어, 안내를 따라 하면서 사용법을 익힐 수 있습니다.
- **계산용**: 실제 계산기처럼 자유롭게 계산해 볼 수 있습니다.

처음 열면 레슨용 모드로 시작하며, 화면 위쪽의 스위치로 두 모드를 오갑니다.

## 지원하는 계산 모드

| 모드 | 내용 |
| --- | --- |
| COMP | 기본 계산: 분수·루트·π 정확값, 삼각함수, 지수·로그, 미분·적분, 메모리 기능 등 |
| CMPLX | 복소수 계산 |
| STAT | 1변수 통계(평균·표준편차), 측정불확도 계산 |
| EQN | 연립일차방정식(2원·3원), 2차·3차 방정식 |
| TABLE | 함수 값 표 만들기 |

## 특징

- 분수, 근호 등을 교과서처럼 표시하는 도트 매트릭스 형태의 화면
- 데스크톱과 휴대폰 화면에 맞춘 반응형 레이아웃
- 서버나 설치가 필요 없는 순수 HTML·CSS·JavaScript

## 로컬에서 실행

저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다.

## 버전

현재 **v1.4** (계산기 본체 오른쪽 위에 표시됩니다).
